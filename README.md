# PanTiltZoom.cam

Welcome to the public home of PanTiltZoom.cam.

PanTiltZoom is a mobile app for controlling PTZ cameras quickly and reliably, with support for camera discovery, presets, and streamlined live-production workflows.

## Changelog

Release notes and historical updates are tracked in [CHANGELOG.md](CHANGELOG.md).

## Report a bug

If you find a problem, please open an issue here:

- [Submit a bug report](https://github.com/theJustinCase/PanTiltZoom.cam/issues/new?template=bug_report.md)

Helpful details to include:

- Device model and OS version
- App version
- Camera model and protocol in use
- Steps to reproduce
- Expected result vs actual result

Have an idea that would improve PanTiltZoom? Open a feature request here:

- [Submit a feature request](https://github.com/theJustinCase/PanTiltZoom.cam/issues/new?template=feature_request.md)
